# Terraform on Azure

A step-by-step course for deploying Azure infrastructure with Terraform.

## Start here

- [Course summary](SUMMARY.md)
- [Lesson 01: Introduction](01-introduction/)
- [Lesson 02: Install Terraform](02-installation/)

## How the course is structured

- Lessons are numbered `01-` through `23-`.
- Each lesson has a `README.md` with the steps.
- Examples live in `examples/` or `terraform/` under the lesson.

## What you will learn

- Terraform basics and Azure provider setup
- Variables, state, and advanced patterns
- Testing, imports, and state operations
- Functions and AI-assisted workflows
